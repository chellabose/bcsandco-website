# bcsandco-website

Website of B C S & Co., Chartered Accountants, Chennai (bcsandco.in).

- The whole site is one file: `index.html`.
- The notes at the top of that file explain how to change wording, phone numbers, the address and office hours.
- A change becomes live when it reaches the `main` branch. GitHub Pages then publishes it within a few minutes.
- Test address: https://chellabose.github.io/bcsandco-website/
- `.nojekyll` is an empty file that tells GitHub to publish the files exactly as they are. Leave it in place.
